# File Uploader

A full-stack file storage application inspired by Google Drive.

## Overview

File Uploader is a web application that allows authenticated users to manage folders and files. Users can create and manage folders, upload files, view file information, and download their files.

The application uses server-side rendering with EJS and Tailwind CSS for the frontend, while Express, Prisma, and PostgreSQL handle the backend and database operations.

## Features

- User registration and authentication
- Session-based authentication with Passport.js
- Create, update, and delete folders
- Upload files to folders
- View file details
- Download files
- File validation
- Cloud-based file storage
- Persistent sessions using Prisma

## Technologies

- Node.js
- Express
- EJS
- Tailwind CSS
- PostgreSQL
- Prisma
- Passport.js
- Multer
